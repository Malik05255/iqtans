# اقتنص — Iqtans

تطبيق Android عربي للعثور على أقل تكلفة نهائية حقيقية للفندق، مع شرح طريقة الوصول إلى السعر عبر منصة الحجز والعضوية والكود والبطاقة والعروض المتاحة.

> هذه النسخة تبدأ بواجهة ومنطق عرض تجريبي واضح. طبقة الأسعار الحية معزولة خلف Repository ولا يجوز وسم أي سعر بأنه «مؤكد» إلا بعد ربط مزود حي وإعادة التحقق منه.

## Google Maps ratings

Google Maps/Places مستخدم كمصدر تقييم مستقل فقط، ولا يدخل في حساب السعر أو التوفير.

- إذا لم يوجد `GOOGLE_PLACES_API_KEY` يستمر الخادم طبيعيًا بدون Google Maps.
- عند النشر على Render أضف قيمة `GOOGLE_PLACES_API_KEY` كـ Secret/Environment Variable ولا تضع المفتاح داخل التطبيق أو المستودع.
- `GOOGLE_PLACES_REVIEW_LIMIT` يحدد أقصى عدد فنادق يتم فحصها عبر Google في البحث الواحد، والقيمة الافتراضية في Render هي `12` لتقليل عدد الطلبات والتكلفة.
- عند توفر Google Maps يظهر attribution ورابط المصدر بجانب التقييم.

بعد إضافة المفتاح أعد نشر خدمة `iqtans-engine`. لا يحتاج APK جديدًا لأن المفتاح يبقى على الخادم.
